03 · The residual

Surprises

β̂ is what mechanism explains; R is what it doesn't. The genes whose residual survives semantic conditioning are where the unrecognized biology lives — not the biggest hits, the ones that break the rule.

Every result is a prediction, shipped with a confidence metric. Hypothesis-generating — publishable on its own, but primarily a segue to experimental validation. Only a bench result is a finding. Rank-based scoring shares one global error term across genes, so trust the pathway before the gene; Phase 0 (+σ) tightens each prediction.
