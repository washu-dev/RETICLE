00 — abstract

TL;DR. 2,157 published CRISPR screens hold the causal evidence for what human genes do, and no two of them are scored the same way. RETICLE puts all of them onto one calibrated axis, so a researcher can ask which published screens are asking the same question as theirs — and what a gene does when the only evidence is a number in somebody else's experiment.

How does my screen compare to every screen in the CRISPR database?

One question. Two ways in — a whole screen, or a single gene.

A CRISPR screen is the closest thing biology has to a direct causal measurement of gene function: perturb every gene, one per cell, and see which knockouts vanish and which take over. Thousands of these screens have been published and deposited, and almost none of them can be read together. Every lab scores its screen differently — we found about 58 distinct score types — and the deposited files do not record whether a larger number means a stronger effect or a weaker one. The result is an enormous body of causal evidence that is effectively write-only: deposited, and never reused together.

RETICLE harmonizes 2,157 published BioGRID ORCS screens onto a single directionally consistent loss-of-function axis, spanning 28.2 million gene-level measurements. On top of that axis it does three things. It ranks which published screens probe biology like yours, using only the genes both screens measured. It builds a gene–gene co-essentiality network directly from screen behaviour, with a mutual-best-match edge rule that stops genes which die everywhere from bonding with everything. And it assembles a per-gene page from ten annotation sources, with an LLM reading the raw score together with the screen's own context — every claim re-checked against the numbers it came from before anyone sees it.

The network reconstructs known biology it was never told about: FANCD2's Fanconi anaemia repair pathway, and CTU2's tRNA wobble uridine modification role, recovered from co-essentiality alone. The whole platform serves for $37.32 a month.

01 — motivation

But we still don't know what most of the genome does.

90% of human genes are barely studied. Biomedical research concentrates on roughly 2,000 of the 19,000 genes in the human genome — and that concentration is historical accident, not a judgement about which genes matter.

A parts list won't tell you which part the engine can't run without — for that, you have to remove one and see what breaks.

1.1 — why that gap mattersA gene nobody has characterised is a dead end for a real patient.

Answers that never come

01 — the clinic

A genetic test finds a change in a gene no one has studied, so the result comes back as a variant of unknown significance — neither positive nor negative. The family waits.

Drugs that never get made

02 — the pipeline

Drug discovery concentrates on proteins that are already well studied. The understudied majority is never even evaluated as a target — not because it failed, but because nobody looked.

The biology in front of us

03 — this lab

The Orvedahl Lab studies cytokine-stress cell death in macrophages. The genes that matter most there are exactly the buffered, under-studied ones current methods are built to miss.

1.2 — the experiment that answers itSequencing gives you the parts list — not what the parts do.

A CRISPR screen does exactly what a parts list cannot. A guide library perturbs each gene, one gene per cell across millions of cells. The pool grows for weeks — on its own, or under a drug or stress. Sequencing before and after shows which knockouts vanished and which took over. Every screen ends the same way: one score per gene.

1.4 — and the data itself doesn't line upThousands of screens exist — and there is no way to use them together.

One gene. Five published screens. Three call it essential, two call it advantageous — and nothing in the deposited data says which convention each one used.
  • 01 · inside one screenA hard cutoff throws away everything below the line · a gene that is absent is stored as if it scored zero · the stimulus, cell type and methods that give a score meaning never make it into the data at all
  • 02 · between screensDifferent stimuli, different cell lines, disagreeing directionality — the same gene gets opposite signs in two experiments and nothing reconciles them
  • 03 · beyond the screensEven once they line up, there is no way to ask the questions that matter: co-essentiality relationships, dark-gene candidates worth chasing, the published literature — and STRING, GO and the screens all live in separate tools

The result: an enormous body of causal evidence that is effectively write-only — deposited, and never reused together.

02 — method

Screens cannot be compared until they speak the same language.

2.1 — harmonizationOne calibrated axis.

Every lab scores its screen differently — about 58 different score types across the corpus. Some scores count up and some count down, and the file does not say which. Two things have to be fixed before any cross-screen arithmetic is meaningful. Scale, because a −7…+2 CRISPR Score and a raw MAGeCK magnitude live on different axes. And direction, because for some score types more negative means essential, while for others larger means a stronger hit. RETICLE harmonizes sign onto one loss-of-function axis and puts all 2,157 screens on it.

one harmonized score
advantageous

2.2 — screen matchingWhich published screens are asking the same question as mine?

  • Scores become ranks, so your screen sits on the same scale as every other one.
  • Your ranked list is compared against all 2,157 screens, using only the genes that both screens measured.
  • The closest matches come back ranked, each one with a confidence value attached.

2.3 — the networkTwo genes are linked when they die in the same screens.

Correlation alone is not enough: a gene that is essential everywhere correlates weakly with everything. An edge survives only if each gene is the other's best match — which is what stops a gene that dies everywhere bonding with the whole genome. Ten sources, and the dark half is still dark.

CRISPR screens carry evidence about exactly those dark genes, but in an uninterpretable form. A score of −7.34 says nothing on its own, and the screen's own description says nothing either. The interpretation lives in the two together — the raw score read alongside the model, modality, assay and duration of the screen that produced it. That is the reading an LLM can do at the scale of 2,157 screens, and every claim it makes is re-checked against the numbers it came from before anyone sees it.

3.3 — why this matters for the dark halfPast studies did not treat every gene with the same attention.

2,000 genes — 9.7% the other 18,620
Those 2,000 hold 52% of every gene-to-paper link in the literature. The top 5,000 hold 74%.

Attention was never evenly spread. For most of the genome the encyclopaedia page would be blank — but the screens have measured it anyway.

04 — system

A whole screen, compared against every published screen.

A 25-gene autophagy list, taken through the platform step by step.

step oneYou hand RETICLE your gene list, and it tells you what it read.

Drop in a ranked screen, or paste a handful of favourite genes. Unpublished screens stay in your WashU session unless you choose to contribute them.

step twoYou say what your screen was, and how much of the corpus to compare it against.

The modality matters — a knockout screen and an activation screen mean opposite things. Everything RETICLE guessed is marked, so you can correct it before anything is compared.

step threePublished screens probing biology like yours, and the pathways behind them.

Every match shows the biology it shares with your screen, and links straight out to the paper. The pathways come back from the gene list alone — autophagy, mitophagy, macroautophagy.

4.1 — architectureRIS builds the corpus. AWS serves it.

The offline/online split is the master architecture fact. WashU RIS (SLURM, GPU and CPU partitions) runs the ETL that harmonizes the corpus; AWS serves it. React and React Native Web on the front end, a FastAPI service on ECS Fargate, a PostgreSQL warehouse on RDS, S3 and CloudFront for the web build, Secrets Manager and KMS for credentials, and WashU Entra SSO for access.

4.2 — statusWhat is deployed, and what is still a prototype.

built and deployed

  • FastAPI service, containerised and running on ECS Fargate
  • PostgreSQL data warehouse and its versioned migrations
  • HPC ETL pipeline on WashU RIS (SLURM, split GPU dedup → CPU load)
  • CI/CD to ECR/ECS and S3/CloudFront, with Secrets Manager and KMS
reference prototype, being productionised
  • Harmonization rules and the directionality fixes
  • The co-essentiality matrix and the mutual-best-match network
  • Darkness scoring and the grounded LLM reading
  • Currently running against SQLite in prototype/, being ported into the production warehouse and service

The science above is real and validated, but a substantial part of it still lives in the reference implementation rather than the deployed service. RETICLE today is a working prototype and a hypothesis-generating tool, not a finished instrument.
