01 — why sequencing isn't enough

Sequencing gives you the parts list — not what the parts do.

what the sequence tells you
  • every gene, located and named
  • ~20,000 protein-coding genes
  • how one person's letters differ from another's
what it doesn't
  • what each gene actually does
  • what happens to a cell when it's lost
  • which genes matter, and under which conditions
A parts list won't tell you which part the engine can't run without — for that, you have to remove one and see what breaks.
01 — what a CRISPR screen is

A CRISPR screen switches off every gene — one per cell.

CRISPR mechanism diagram / animation still
assets/crispr_mechanism.png
Cas9 guided to one gene per cell — a library of guides covers the whole genome
the experiment, in three steps
  • perturbA guide library disables each gene — one per cell, across millions of cells
  • selectThe pool grows for weeks — on its own, or under a drug or stress
  • read outSequence before and after — which knockouts vanished, which took over
dropped out → the gene was essential
took over → losing it helped

This is rare data: the measured result of actually breaking each gene — cause, not correlation. Every screen ends the same way: one score per gene.

02 — and the data itself doesn't line up

Thousands of screens exist — but no two speak the same language.

Context is missing

01 — can't compare

What a score means — what was perturbed, under what stress, in which cells — is usually left in the methods section. So rank #132 in one screen is not rank #132 in another.

Cutoffs hide the buffered genes

02 — can't see

Every screen draws a line: above it are "hits," the rest is discarded. Genes whose function is backed up by a partner are real but modest — and always fall below the line.

Absence is read as zero

03 — can't trust

Many screens deposit only their hit list. A missing gene might have scored near zero, or might never have been measured — opposite facts that no current method tells apart.

Together: an enormous evidence base that is effectively write-only — deposited, and never reused in aggregate.

03 — how the wiki is built

Ten sources, joined offline on one key.

1 · fetch
All ten pulled in full, not per request.
2 · join
Every record keyed on one GeneID, so the ten agree which gene they mean.
3 · embed
Chunked and embedded into pgvector, beside the screens.
4 · retrieve
The page answers from that, in a quarter of a second.

Nothing is fetched while you wait, so ten sources cost what one does — and every sentence keeps the source it came from, which is what a summary alone cannot give you.

significant if < −1.5
the one question
Which direction means the cell died?
Read from the screen's own words, then anchored against genes already known to be essential.
comparable
−1 died+1 grew
Every screen on one scale — 28.2 million measurements.

Labs score with MaGeCK, CERES, CasTLE and raw log2FC. The magnitudes cannot be compared and the signs disagree about which direction is bad — that is the whole obstacle, and it is the only place a model is used.

03 — step four

If we trust the neighbours, we can name what a dark gene does.

1 · gather
Its co-essential neighbours and their known functions.
2 · propose
A shared process it is not yet annotated with.
3 · verify
Re-checked: novelty, and every cited neighbour.
4 · label
Ships as verified, single-supporter, or rejected.

A cited partner that is not really in the neighbourhood is dropped before you see it. Leave-one-out says the signal is real, not circular.

04 — what's next · Aaron

Future goals

Three things that would turn a working tool into a working method.

04 — goal one

Take one prediction to the bench and find out if we are right.

Every prediction already ships as a testable claim: this gene participates in that process, because these named partners do.

CORUM says how often an edge is a real complex. Only an experiment says whether a new claim is true. Nobody has run one yet.

04 — goal two

Every new screen makes the network sharper for everyone.

today
2,157 published screens · 5,077 genes reach the network.
the gap
Another 15,500 genes have too little signal yet.
the fix
Unpublished screens from labs like ours.
the return
A contributing lab sees its screen placed in context.

This is the part that compounds. Coverage is not a software problem — it is a collaboration problem.

04 — goal three

Open the API so other tools can ask our questions.

The whole product is already a REST API — the website is just its first client. Documenting and opening it is a small step with a large reach.

A pipeline could score its hits against 2,157 screens without a browser. The data is only useful if it can leave the page.
